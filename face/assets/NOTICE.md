# Notices for face/assets

`skin.png` and `../lib/sprites.js` are generated by `face/tools/gen-skin`.

## Pyxamp skin (sprites, Pyx 5x6 and 9x13 fonts, label set, compass mark)

Drawn from the original pixel maps and primitives in `docs/mock/skin.js`,
made for Pyxamp. No Nullsoft, Winamp or Webamp bitmap is loaded, traced or
copied (ADR 0002). Same licence as the rest of this repository.

## W95FA Grid glyphs (playlist, menus, tooltips)

The W95FA Grid glyphs in `skin.png` are a bitmap rendering, at one font pixel
per skin pixel, of `docs/mock/fonts/W95FAGrid.ttf`.

- W95FA 1.002 by FontsArena (Alina Sava), https://fontsarena.com/w95fa/,
  licensed under the SIL Open Font License 1.1. The licence text is in
  `licenses/W95FA-OFL.txt`, unchanged from the upstream release. The upstream
  file keeps the OFL template header (`Copyright (c) <dates>, <Copyright
  Holder>`) and declares no Reserved Font Name.
- "W95FA Grid" is a modified version (points snapped to the font's 80-unit
  pixel grid, advances trimmed to whole pixels, a few added glyphs), made by
  mountainous's `scripts/w95fa-grid.py`. The name differs from the original, as
  the OFL asks of modified versions.
- The OFL allows bundling the font, and works derived from it, with software,
  provided the licence and copyright notice travel with it. This file and
  `licenses/W95FA-OFL.txt` are that notice. The glyph bitmaps are not sold by
  themselves.

## ChicagoFLF (the Platinum face)

`ChicagoFLF.ttf` is ChicagoFLF 2.1, the same file as mountainous's
`chicagoflf` package (`modules/fonts.nix`). The face loads it itself, so it
never depends on the host's fonts. `lcd-font.png` and `../lib/lcdfont.js` are
a 1-bit rendering of it at 12 px, made by `face/tools/gen-lcd-font`.

- Robin Casady, the designer, placed ChicagoFLF in the public domain (his
  statement is in `licenses/ChicagoFLF-README.txt`, unchanged from the
  upstream release).
