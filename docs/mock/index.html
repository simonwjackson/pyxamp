Mock controls

Outside the Pyxamp surface. Picking a state resets the mock to it.

Keys (click the desktop first): Z X C V B transport, J jump box, L library, R repeat, S shuffle, Ctrl+D double, Ctrl+T time, Alt+W shade, Alt+G EQ, Alt+E playlist, Alt+3 item info, Super+Z show/hide, Esc closes. Right-click a playlist row for its menu.
